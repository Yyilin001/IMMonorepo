# Gateway 10,000 条 TLS 连接、1,000 条慢读取连接：本机传输实验

日期：2026-09-26
状态：限定的传输层实验；不是完整网关容量或生产 SLO 验收

## 问题与结论

在同一进程中建立 10,000 条真实 TLS 客户端连接，其中 1,000 条在握手后停止读取。
使用生产 `V2NIOGatewayForegroundWriter` 和事件循环写调度器发送前台字节。
本机固定速率实验中，先把慢连接推到不可写状态，再向所有连接发送 120 轮公共数据；
其余 9,000 条正常连接全部收到完整公共数据和最后的探针。
探针 p95 为 73.6 ms，对照组为 80.9 ms；这两次运行没有观察到慢连接拖住正常连接，
但一次运行之间的延迟差值不能作为性能提升或 SLO 证明。

## 方法

- 主机：Apple Silicon macOS，48 GiB 物理内存；客户端和服务端在同一个测试进程中，
  共用 8 个 NIO 事件循环线程，经 127.0.0.1 通信。
- 每组建立 10,000 对 TLS 套接字。对照组全部读取；慢连接组有 1,000 个客户端
  在 TLS 握手后关闭自动读取。服务端与客户端均请求 4 KiB 套接字缓冲区，
  实际缓冲大小仍由操作系统决定。
- 公共流量：每 100 ms 向所有连接提交一份 1 KiB 字节块，共 120 轮，然后提交
  一份独立的 1 KiB 探针。每条正常连接应收到 123,904 字节。
- 为确保慢连接组真正触发背压，公共流量前另外向每条慢连接快速提交
  40 份 64 KiB 数据。该约 2.44 GiB 是逻辑提交量；有界前台队列会保留有序前缀
  和最新恢复帧，不能把提交量解释成实际网络发送量。
- 探针延迟从提交前的时间点计到客户端收到探针；RSS 是测试进程在结果快照时
  的驻留内存，包含客户端与服务端，且不是峰值。

## 结果

| 指标 | 无慢连接 | 1,000 条停止读取且已预装积压 |
| --- | ---: | ---: |
| TLS 握手完成 | 10,000 | 10,000 |
| 正常连接收到探针 | 10,000 / 10,000 | 9,000 / 9,000 |
| 正常连接最少收到的公共数据和探针 | 123,904 B | 123,904 B |
| 探针 p50 / p95 / p99 | 67.4 / 80.9 / 83.3 ms | 61.5 / 73.6 / 76.5 ms |
| 前台写入因不可写而延后 | 0 | 1,000 |
| 首次保留恢复帧 / 后续替换 | 0 / 0 | 1,000 / 155,745 |
| 单连接前台队列观测峰值 | 1,024 B | 327,680 B |
| 测试进程快照 RSS | 1,220 MiB | 1,336 MiB |

慢连接组的 327,680 B 包含 256 KiB 有序队列预算之外的单份 64 KiB 恢复帧。
两组 RSS 相差 116 MiB，但由于压测客户端也在同一进程，不能把差值直接归因于 Gateway。

校准时还试过把 120 轮公共数据在约 2.4 秒内一次性提交：正常连接也出现大量队列溢出。
该轮没有匹配的无慢连接对照，因此没有纳入上述比较；它提示突发速率仍需单独测量。

## 适用范围与复现

实验复用了生产前台写者、分 EventLoop 调度器和真实 TLS 套接字；测试数据是原始字节块，
没有经过网关 protobuf 帧编码，也没有运行 `V2NIOGatewayChannelHandler` 的认证/命令处理、
数据库、NATS、持久房间日志及客户端游标补拉。因此它只能支持传输层隔离判断，不能证明
10,000 个已认证用户的完整消息可见延迟或故障恢复能力。
两组各运行一次，尚需多次重复和独立机器上的客户端/服务端测量。

手动执行；普通测试运行会将此容量实验标为禁用：

```bash
cd IMV2Server
IMV2_RUN_SLOW_FANOUT_BENCHMARK=1 IMV2_SLOW_FANOUT_PAUSED=0 \
  swift test --filter V2GatewaySlowFanoutBenchmarkTests
IMV2_RUN_SLOW_FANOUT_BENCHMARK=1 IMV2_SLOW_FANOUT_PAUSED=1000 \
  IMV2_SLOW_FANOUT_PRELOAD=1 \
  swift test --filter V2GatewaySlowFanoutBenchmarkTests
```

实验实现位于 `IMV2Server/Tests/IMV2ServerTests/V2GatewaySlowFanoutBenchmarkTests.swift`。
