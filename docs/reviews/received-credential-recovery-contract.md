# 已收到签发结果的持久交接

日期：2026-09-07。范围为 B08；整体仍实施中。PostgreSQL 28、protocol 27、SQLite 173/5 不变。

## 实现与顺序

HTTP issuer 解码并确认设备匹配后，先把 user/device、撤销 capability、绝对期限和注册 operationID 写入独立 Keychain 记录，再返回登录凭据。记录不包含 access token、refresh credential 或账号密码。其可用性为 AfterFirstUnlockThisDeviceOnly，格式版本为 1，最多 256 条；损坏、冲突或容量不足显式失败，不覆盖既有记录。

正常登录先由 AuthSession 保存凭据，再退休注册操作，最后删除已接管的中间记录。若保存凭据后进程退出，冷启动用实际持久凭据的 user/device/capability/期限识别已接管结果，只移除中间记录。带退出标记的凭据不算接管。

取消或认证 epoch 失效时，bootstrap 先通过已有串行 credential IO 读取持久所有权；已经被另一代保存的同一会话完成接管，其他结果先持久标记 abandoned，再交给独立撤销队列。队列写入失败保留中间记录；队列成功后中间记录删除失败也可重试。交接与既有相同会话退出任务重合时，保留原操作 ID、次数、暂停和退避，不重置进度。actor 在跨队列 await 后重新读取并比较记录，避免删除期间变化的值。

App 在冷启动、允许交互登录之前对照真实 Keychain 执行一次恢复。没有被持久凭据接管的旧记录转为 abandoned。前台执行器与显式重试先转交 abandoned 记录；不可读取或交接失败显示恢复提示。凭据保存结果不确定的 awaitingAdoption 记录保留至冷启动核对，不在活跃注册期间把它自动当成废弃结果。

- ClientKit 完整回归：452 项报告、447 项实际执行、5 项在线跳过，71 套件，5.940 秒。新增六项恢复存储测试、一项实际 HTTP issuer 组件测试及 bootstrap 的取消/退出/替换/同会话已接管四种结果测试。
- App 带签名单元回归：197 项报告、196 项实际执行、1 项在线跳过，20 套件，4.913 秒。真实模拟器 Keychain 覆盖孤立结果恢复和已有登录识别，并验证可用性属性及测试域清理。
- 真实 HTTPS 与独立 PostgreSQL：5 项、2 套件、2.648 秒；签发测试显式使用生产恢复 actor 和内存持久适配器，断言返回前已写记录、完成后清除且没有误排撤销。设备/撤销持久计数为 7|3|0|0|3，撤销能力兑换 204×4、401×1、409×1。自建数据库和证书目录已独立核实移除。
- 完整离线回归先于最后的在线测试夹具改动；之后在线运行覆盖该夹具。生产代码在两次运行间未改动。源码散列、原始日志和 xcresult 汇总见[证据清单](evidence/20260907-issued-result-recovery/manifest.json)。xcresult 首次在沙箱内导出被文件权限阻止，随后正常授权导出成功；这不是测试失败。

## 未覆盖与剩余工作

完全丢失签发响应时，客户端仍没有服务端生成的撤销 capability；本改动不解决这个窗口。即使 HTTP 已返回，第一次中间记录写入失败仍需保留注册操作供重放，不能宣称所有返回结果均已持久化。服务端默认绝对会话期限仍是已有上界，不等同于即时撤销。

现有 App 依靠交互登录 gate 和退出后的注册身份轮换控制注册。已覆盖“同一结果已被另一代持久接管”，尚未证明任意多个 SDK 调用者共享注册身份、其中一个仍准备接管时的全部交错。冷启动恢复 API 明确不得在当前进程注册在途时调用。

本批未执行真正逐指令强杀、真机锁屏/首次解锁、OS 后台调度、完整 UI/Gateway/headless 链路。组件重建和故障注入提供持久状态边界证据，不冒充系统级强杀验证。B08 保持实施中，47 项仍为 16 项已验证、31 项开放。
