## 测量边界

- 每个种子房间有一条正文，首次本地数据库为空，第二轮复用 SQLite；不代表长期活跃账号或大历史缺口。
- 五档所选整轮驱动及 HTTP/数据库终验通过。129/1000 所选结果使用双 Gateway/NATS。
- 50/129/1000/10000 在线阶段无需详细订阅或手动补拉；129/1000/10000 的目标是目录第 129 个房间。
- RSS 约每秒采样，可能漏掉短峰值；只包含主 Gateway 和测试宿主，不包含 PostgreSQL、第二 Gateway、NATS、模拟器系统和编译器总资源。0 场景太短，资源样本为空；1000 旧记录未采集资源；当前记录已独立汇总，见千房间资源段。
- 部分测试期间有编译活动，耗时不作为隔离延迟 SLO。
- 逻辑字节包含请求/响应帧及帧头，不含 TLS、握手和异步通知，不是网卡总流量。
- 首屏标记只表示本地可查询到最多 20 条列表记录，不是 UI 首帧时间。
- 结果不能推出任意账号都在固定时间完成；冷热偏斜、多用户并发和跨分片资源仍需验收。
