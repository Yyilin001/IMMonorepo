# 设备会话绝对期限

2026-09-07，B08 服务端期限阶段。PostgreSQL 当前合同升至 **26**；protocol 27、SQLite 173/5 和 HTTP 凭据响应字段不变。此阶段为有限期的离线撤销能力建立前提，尚未签发该能力，也未接通 App 远端退出补偿。

## 当前行为

`auth_devices.session_expires_at` 保存设备会话绝对截止，必须是有限的非空时间。生产签发默认设为注册时刻之后 30 天；服务构造参数允许 1 秒至 366 天。首次凭据及每次刷新生成的 access/refresh 到期时间均不超过该截止，刷新不会推进设备截止。预建且尚未签发凭据的设备也只能收紧期限。

到期或已撤销设备不能通过注册/刷新操作记录重新取得凭据。HTTP 共用的 PostgreSQL Gateway authenticator 独立检查设备期限，返回的认证租约取 access token 与设备截止的较早者，并在读取返回后再检查当前时间。即使旧 access 行期限过长，也不能越过设备截止授权。Gateway 到期后不再返回可供命令和主动输出使用的认证身份或帧合同；未测试内核连接在截止瞬间被关闭。

活跃设备列表和注册数量预算排除已经到期的设备。Push endpoint 读取、注册、意图读取/认领/发布，设备快照可用性，以及媒体授权均校验期限。需要跨提供方调用的下载和上传，在最终兑换时再次验证当前授权；上传完成上报也不能绕过设备检查。使用数据库时钟的媒体、Push 读取/意图和快照检查采用 `clock_timestamp()`，避免把事务开始时的时间一直用于后续兑换。其他入口保留注入的当前时钟或操作时间，Gateway 另有读取返回后的时钟复核。

## Schema 与迁移

新环境直接安装 schema 26。受控测试数据可在停止凭据写入后运行 `20260907_device_session_absolute_expiry.sql`：旧设备按原 `created_at + 30 days` 回填，不从迁移时刻重新延长。已经到期的设备在同一事务撤销 access/refresh、禁用 Push、追加幂等撤销事件；其他设备的凭据期限被收紧。迁移明确拒绝重复应用。

Swift 启动检查和 SQL 合同检查同时要求期限字段和有效的有限值约束。测试分别删除字段、删除约束，确认仅保留 schema 26 标记不能绕过检查。历史领域迁移夹具补齐到 26；那些测试的可用设备明确设为近期设备，真正的过期回填由独立迁移场景验证。

## 验证

- **19 项真实 PostgreSQL 测试 / 1 套件，62.456 秒**：覆盖截止前刷新、截止时的普通请求和重放拒绝、旧超长期限 access 行的独立认证限制、活跃名额释放、真实 Push endpoint、上传授权各阶段、提供方返回期间的下载到期、快照可用性及历史迁移。参数化场景包含 shared/inline 旧媒体路径和跨 owner 消息媒体路径。
- **54 项服务端单元测试 / 7 套件，0.059 秒**：Gateway 会话/字节流、认证中间件、凭据/设备路由、撤销 worker、媒体提供方服务。
- **迁移验证**：独立 schema 25 中准备近期和过期设备，实际迁移后核对创建时间锚定、有效凭据上界、过期凭据与 Push 失效及撤销事件；完整 SQL schema 合同通过，重复迁移被拒绝。
- **真实 App 组合回归**：2 项 UI 分别通过 Gateway/HTTP 撤销、冷启动及同账号重新登录（38.076、31.633 秒）；5 项 HTTPS 测试通过（2.710 秒）；独立 delegate/store 后台入口 1 项通过（1.286 秒）。这组正常流回归没有等待真实的 30 天到期，也不代表 APNs 或系统无 scene 冷启动验收。

真实组合最终数据库计数 `15|5|0|0|5`，UI 和后台测试清理后 Gateway 均为 0。临时数据库、私有证书和专用模拟器已清除。首轮 PostgreSQL 回归的一个历史迁移链版本失败也保留在[证据](evidence/20260907-session-absolute-expiry/manifest.json)，未隐藏或计作通过。
