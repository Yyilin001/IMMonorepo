# D02/D03：真实凭据的无根页面 Push 入口验证

本批补齐已有生产实现的集成证据，未修改 App/ClientKit/Server 生产 Swift 代码。D02/D03 保持实施中。

测试在 iOS App 测试宿主中创建独立 delegate/store，不给这个 store 创建 `V2RootView`，也不调用 scene active。宿主本身仍具有系统启动设施，因此这不是操作系统无 scene 冷启动或 APNs 投递测试。

## 实际链路

通过真实账号 HTTPS 注册、签发设备凭据并写入独立 Keychain 域。被测 delegate 的 store 从 launching 开始，通过系统回调适配器恢复凭据、打开账号 SQLite 并连接真实 TLS Gateway。使用系统 SQLite 只读连接检查 ready 游标、非空 token、applied 与 acknowledged 一致；第二次 Push 返回 noData，序号不重复推进。

另一台真实认证设备随后撤销被测设备。后续回调返回 failed，认证观察者清除旧界面与 Keychain；等待 signedOut 后再发 Push 返回 noData。每次回调检查 completion 一次完成。清理先停止旧 store，再使用独立测试域的清理入口；撤销者自己的测试 Keychain 项也删除。

脚本新增显式 `--headless-app`，要求同时使用 `--app-ui --gateway`。测试默认关闭；脚本要求在线用例实际执行 1 项、通过 1 项且跳过 0 项，避免把未运行误记为通过。每次使用新数据库、证书和模拟器，保留失败证据并清理资源。

## 验证结果

最终无根页面入口测试 1 项 / 1 套件通过，耗时 1.310 秒；4 项真实 HTTPS 通过（2.627 秒），2 项真实认证终止/冷启动 UI 通过（60.012 秒）。持久设备/撤销/未撤销 access/未撤销 refresh/撤销事件计数为 11|4|0|0|4；UI 和无根页面测试结束后 Gateway 认证连接为 0。

最终普通 App 回归报告 193 项 / 19 套件（4.940 秒），其中 192 项实际执行，新在线测试按条件跳过。本批没有重新运行完整 ClientKit/Core/Server 套件，生产实现保持上一批版本。

首轮测试编译缺少宏内部 try，随后直接使用 GRDB 的游标检查因测试目标未链接 GRDB 而失败；现改为系统 SQLite 的独立只读检查。第二轮既有 UI 测试在登录入口刚出现时立即检查旧弹层，捕获了页面切换附近的一帧；录像显示随后已移除，现以最多 5 秒观察旧页面消失，仍要求登录入口和旧页面消失同时成立。第三轮入口的恢复、同步与重放断言通过，但测试误用禁止撤销当前设备的管理接口；现由另一认证设备按原合同撤销，未改变服务端策略。

全部失败、最终日志、源码哈希、录像和截图见[证据](evidence/20260906-headless-push-entry/manifest.json)。四次尝试的私有数据库/证书目录和专用模拟器均已核对删除。最终两张冷恢复截图显示退出后的空登录表单。

## 剩余验收

真实 APNs 投递、系统无 scene 后台冷启动、锁屏/首次解锁、长磁盘操作以及系统回调时间上限仍未验证。本测试证明共享 delegate 入口能在未给被测 store 创建页面时运行真实认证与同步链路，不能替代以上系统和设备验收。
